Controller Area Network, one bit at a time.

CAN is a multi-master serial bus. There are no node addresses: every frame carries an identifier that names its content and sets its priority. Bosch started developing it in 1983, presented it at the SAE Congress in 1986, and it went into series production in the 1991 Mercedes S-Class. ISO first standardised it in 1993 as ISO 11898.

The 3D model is interactive. Click an ECU to transmit its frame along the twisted pair. Press Simultaneous start to see bitwise arbitration: the lowest identifier wins and no bus time is lost.

01 · Physical layer (ISO 11898-2)

Dominant beats recessive

High-speed CAN uses a differential pair. In the recessive state (logic 1) nobody drives the bus and both lines rest near 2.5 V. In the dominant state (logic 0) CAN_H rises to about 3.5 V and CAN_L falls to about 1.5 V. Receivers read only the difference: below 0.5 V is recessive and above 0.9 V is dominant. The bus behaves as a wired-AND: one dominant transmitter overrides any number of recessive ones. A 120 Ω resistor terminates each end of the line.

Try it

Click the bit buttons to change the pattern, then add common-mode noise. The noise moves CAN_H and CAN_L together, so Vdiff stays clean. This is why CAN uses a twisted pair.

02 · Data link layer: the frame

Frame builder, with live CRC and bit stuffing

Enter an identifier and payload. The builder assembles the bit sequence as in Bosch CAN 2.0 Part B: it computes the 15-bit CRC (polynomial x¹⁵+x¹⁴+x¹⁰+x⁸+x⁷+x⁴+x³+1) and inserts a complementary stuff bit after every five identical bits, from SOF through the CRC sequence. 03 · Medium access: CSMA with bitwise arbitration

Arbitration lab

Nodes that start together send their identifiers MSB first while reading the bus back. A node that sends recessive (1) and reads dominant (0) has lost arbitration. It stops transmitting at once and becomes a receiver. The frame with the lowest identifier gets through intact. With equal identifiers, a data frame (RTR dominant) beats a remote frame.

Contending nodes (11-bit IDs)

Bosch CAN 2.0 Part B, “Message Transfer” and “Basic Concepts: Arbitration”. Two nodes must never send data frames with the same identifier.

04 · Error detection & fault confinement

Error counters and the fault-confinement state machine

CAN detects five error types: bit, stuff, CRC, form and acknowledgement errors. Every node keeps a transmit error counter (TEC) and a receive error counter (REC). A node with a persistent fault therefore removes itself from the bus before it can block everyone else. The Bosch specification gives a residual probability of an undetected corrupted message below message error rate × 4.7·10⁻¹¹.

Error flags are followed by an error delimiter of 8 recessive bits. A successful reception decrements REC when it is 1–127. When REC is above 127, a successful reception sets it to a value between 119 and 127; this model uses 127. Only TEC can drive a node to bus-off.

05 · Bit timing & synchronisation

Bit-timing calculator

Each bit time is split into time quanta (TQ): SYNC_SEG (1 TQ, where an edge is expected), PROP_SEG (compensates the physical delay), PHASE_SEG1 and PHASE_SEG2. The bit is sampled at the end of PHASE_SEG1. Nodes resynchronise on recessive-to-dominant edges by stretching PHASE_SEG1 or shortening PHASE_SEG2 by up to SJW. Because arbitration needs every node to see the same bit in the same bit time, the bit time must cover the round-trip propagation delay. Longer buses therefore need lower bit rates.

Constraints checked

  • The bit time is programmable from at least 8 to 25 TQ (Bosch CAN 2.0).
  • The prescaler is an integer from at least 1 to 32: fCAN / (bit rate × NTQ) must be a whole number.
  • SYNC_SEG = 1 TQ. The information processing time (IPT) is ≤ 2 TQ.
  • Bosch CAN 2.0 (1991) fixes PHASE_SEG2 = max(PHASE_SEG1, IPT), with PROP_SEG and PHASE_SEG1 each 1–8 TQ. ISO 11898-1 lets PHASE_SEG2 be set on its own, with a minimum configuration range of 2–8 TQ. That allows the late sample points (around 87.5 %) that CANopen practice recommends.
  • SJW is 1–4 TQ and no longer than either phase segment.
  • Only one synchronisation is allowed per bit time, and only on recessive→dominant edges.

Most modern controllers combine PROP_SEG and PHASE_SEG1 into one register field (TSEG1), which is what this calculator outputs. Their limits differ by vendor, so check your reference manual.

Bosch CAN 2.0 Part B, “Bit Timing Requirements”, which also gives a maximum oscillator tolerance of 1.58 %. ISO 11898-1 Phase_Seg2 range per Microchip MCAN errata and Bosch’s ISO-conformant bit-timing table. The 87.5 % recommendation is from CANopen practice (CANpie bit-timing table).

06 · Real-time guarantees

Worst-case response-time analysis

Once a frame starts, it cannot be pre-empted, and arbitration always picks the highest-priority pending frame. CAN therefore behaves like fixed-priority non-preemptive scheduling. Tindell, Burns and Wellings (1994) derived its schedulability analysis. In 2007 Davis, Burns, Bril and Lukkien showed that the original analysis is optimistic: it can guarantee messages that actually miss their deadlines. They published the revised analysis implemented below. Load their counterexample and switch between the two analyses.

Cm = (g + 8sm + 13 + ⌊(g + 8sm − 1)/4⌋)·τbit g = 34 (11-bit ID), 54 (29-bit ID) → 135 bits for 8 bytes, 11-bit ID
Bm = maxk∈lp(m) Ck
tm = Bm + Σk∈hep(m) ⌈(tm + Jk)/Tk⌉·Ck Qm = ⌈(tm + Jm)/Tm⌉
wm(q) = Bm + q·Cm + Σk∈hp(m) ⌈(wm(q) + Jk + τbit)/Tk⌉·Ck
Rm = maxq=0..Qm−1 ( Jm + wm(q) − q·Tm + Cm )

Equations 1, 5, 8, 10, 11 and 13 of Davis et al., Real-Time Systems 35(3):239–272, 2007 (doi:10.1007/s11241-007-9012-7). Times in ms. Priority 1 is highest; lower ID means higher priority. The counterexample uses 125 kbit/s and 7-byte frames, so C = 1 ms exactly. Message C is reported as 3 ms by the original analysis but its true worst case is 3.5 ms, beyond its 3.25 ms deadline. 07 · Three generations

Classical CAN → CAN FD → CAN XL

CAN FD (Hartwich, Bosch, iCC 2012) keeps arbitration at the nominal rate. Once arbitration is over, the BRS bit can switch to a faster data-phase bit rate, and the data field grows to 64 bytes. CAN XL, the third generation, separates priority from addressing and carries up to 2048 bytes. All three are now in ISO 11898-1:2024.
